# Belgian Urban Heat Monitor

Predicts urban heat anomalies across Belgian cities using Sentinel-2 satellite imagery, citizen science weather sensors, and EU imperviousness data.

## What it does

Trains an ML ensemble (Random Forest, XGBoost, stacked meta-learner, CNN) to predict how much hotter or cooler a location is compared to the city daily mean. The dominant predictor is EU HRL sealed-surface fraction (IMPERVIOUSNESS). Produces interactive heat anomaly maps for Leuven (2023–2025) and zero-shot inference for Brussels, Ghent, Antwerp, and Liège.

## Data sources

| Source | What | Access |
|---|---|---|
| [Leuven.cool](https://zenodo.org/records/14893734) | ~600 weather stations · Q3 2023–2025 | Free (Zenodo) |

| [RMI AWS](https://opendata.meteo.be/geonetwork/srv/eng/catalog.search#/metadata/RMI_DATASET_AWS_10MIN) | 5 Belgian cities · official daily temperature baseline | Free (CC BY 4.0) |

## How to run

1. Download Sentinel-2 scenes from [Copernicus Browser](https://browser.dataspace.copernicus.eu) — tiles T31UFT (Leuven/Liège) and T31UES (Brussels/Ghent/Antwerp), cloud cover ≤ 10%, Q3 summer dates — and save as `data/raw/sentinel2/YYYY-MM-DD/BXX.jp2`
2. Place Leuven.cool CSV files in `data/raw/leuven/`
3. Run `notebooks/heat_monitoring_intelligence.ipynb` top to bottom
4. Open `dashboard/urban_heat_v3.html` in a browser

## Results

8-feature model (NDVI, NDBI, B11, HUMIDITY, ALTITUDE, wind_ms, SOLARRADIATION, IMPERVIOUSNESS):

| Model | RMSE (°C) | MAE (°C) | R² | CV RMSE |
|---|---|---|---|---|
| Random Forest | 0.426 | 0.264 | 0.581 | 0.497 |
| XGBoost | 0.422 | 0.259 | 0.588 | 0.490 |
| XGBoost (tuned) | 0.422 | 0.258 | 0.588 | 0.484 |
| **Stacked RF+XGB** | **0.416** | **0.255** | **0.599** | — |
| CNN (100 epochs, GPU) | 0.527 | 0.310 | 0.369 | — |

Best model: Stacked RF+XGB ensemble (R² = 0.599). LOSOCV RMSE = 0.575 ± 0.460 (spatial leakage check). Spatial maps cover Leuven (trained) and zero-shot inference for Brussels, Ghent, Antwerp, and Liège using real Sentinel-2 T31UES data.

## Known limitations

- Training data is Leuven only — multi-city generalisation is zero-shot, not validated; LOSOCV gap (+0.16°C) quantifies spatial autocorrelation
- 2024 has only one Sentinel-2 scene, which causes higher prediction error for that year
- CNN (100 epochs, Tesla T4 GPU) trails tree ensembles at R² = 0.369 — spatial patch features alone are insufficient at this dataset size
- Grid prediction range is narrow because weather features are fixed at station-median values, not spatially interpolated
